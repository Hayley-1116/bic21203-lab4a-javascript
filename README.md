## Overview
Three small pages using HTML and JavaScript: a text changer (Q1),
a number validator (Q2) and a dynamic list generator (Q3).

## How to run
Open the `index.html` file in each folder in a browser (no server needed).
- `q1/index.html` – click "Change Message".
- `q2/index.html` – enter a value and click "Check".
- `q3/index.html` – click "Generate" repeatedly.
